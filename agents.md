# Agents Guide — NEON OVERDRIVE

The game is a set of ES modules (see README "Project layout"). All mutable world state lives on one object, `G` (`src/game/state.js`); the logical playfield is `view.W = 450` wide and `view.H` tall (depends on aspect).

`G.scriptCtrl` (a function returning the same shape as `player.js control()`) overrides ship control; the boot intro uses it. Starting a run (`newWorld("run")`, so `launch` / `startRun` too) aborts a still-playing boot intro, so bot runs on a fresh page no longer fly its script.

Set `G.autopilot = true` to let the built-in bot (`src/game/bot.js`) fly a real run; `G.player.god = true` for invulnerability.

Example balance check:

```js
NEON.startRun("vector");
NEON.G.autopilot = true;
NEON.simulate(600); // → { screen, sector, hp, level, score, time }
```

## Art

- Sprites bake once at boot (`buildSprites`, `buildEnemySpritesV2`, `prewarmBossArt`). Ships (`shipArt.js`), enemies (`enemyArt.js`) and bosses (`bossArt.js`) are layered line art built with the `ink.js` kit: dark-glass hull parts with a colour wash and glowing rim, panel seams, vents, rivets, lights, nozzles, canopies. Detailed sprites bake at res 3 (`makeSprite(size, draw, flash, res)`; `g.blurK` keeps glow radii constant). Enemy box sizes match their hitboxes; directional enemies face +y.
- Bosses: static bodies are cached per colour (with a flash copy, blended at 0.2 when hit); `bosses.js` draws the moving pieces per frame (Warden legs/turrets/reactor, Hydra tentacles/eye, Omega rings/nodes/tethers, Eclipse plumes). Boss `parts(e)` hitboxes did not change.
- `flame(color)` (sprites.js) is the stretched engine-flame sprite; explosions also throw tumbling `shard` debris particles (fx.js).
- Shots (`src/render/shots.js`): each primary weapon has a ki-style **shot style** baked per bullet colour (`shotStyle(weapon, c, makeSprite)`; pastel paints are pushed to a vivid hue by `vivid()` so overlapping shots don't wash to white). A style is a sprite (`img/size/half`) plus `frames[]` (animated head, cycled at `fps`, offset by `b.seed`), `spin` (rad/s; 0 = points along the flight), `trails[]` with `tl/tw` (a strip drawn from the head backwards, growing in over `b.age`), `hit` / `pop` (the impact pop `fx.impact` makes in `collide`). Styles: pulse ki barrage, lance spiral beam, scatter destructo discs, phase masenko crescents, ricochet thunder bolts, charge spirit orb, wave ghost wisps, burst death beams, spark star sparks, shard crystal shards; `superKi` is the Striker Overdrive gold round (`S.pb_od`), `moduleShot` / `withTrail` give drone, frag, nova, reflected shots and missiles a comet tail. `drawPlayerBullets` draws trail + head (two drawImages per shot); plain sprites without `frames` (blades) draw as before. The rail lance is a ki beam wave (`modules.js kiBeam`).
- Particles (`fx.js particle(kind, ...)` returns the particle): `spark dot ring flash shard` plus `shock` (soft shockwave band, `shockSpr`), `flare` (cross lens flare, `flareSpr`, `p.rot`), `ember` (flickering drifting glow that falls back with the scroll), `glint` (twinkle, `glintSpr`) and `bolt` (lightning crackle; `vx, vy` = direction, `size` = length, points baked into `p.pts`). `explosion` layers flash, flare, shock, sparks, shards, dots, embers, glints and (size >= 1.2) bolts.
- Enemy shots are solid pellets (dark halo and outline, hot rim, white core, no trail, a faint throb) so they never look like the additive, trailing player ki. **Shootable** enemy projectiles are any `eBullets` entry with `hp > 0` (`shoot(..., {hp})`; `maxHp` is kept): they are drawn armoured with a turning lime target ring (`S.eb_target`, lime is reserved for this) and an HP arc (`drawArmored`), take player-bullet hits in `collide`, and are skipped by bullet-erasing beams and the orbital. Types: `torpedo` (WARDEN) and `shell` (tanks lob one with their heavy fan from sector 3, or when elite: an armoured hex bomb that slows to a stop and bursts into `burst` small shots when `fuse` runs out; its fuse light blinks faster as it runs down).

## Enemy roster notes (step 6a)

- TYPES in `enemies.js` (`hp` is scaled by `diff.hp`; `keep` = never despawned, `plain` = no elite roll). Beyond the originals: **carrier** (descends, hovers, launches 3 diving swarm pods up to 3x), **shielder** (tethers a shield to up to 3 nearby enemies via `e.links` / `target.shieldedBy`; `damageEnemy` takes -80% while the shielder lives; drawn by `drawShieldLinks` in world.js), **weaver** (spawned in pairs by `spawnWeavers`; the lead node owns an enemy beam in `G.beams` with `len` = segment length, `tele` 0.6s; it vanishes when either node dies; beams without `len` are 1400px rays), **blinker** (fade in, 0.5s ring telegraph, ring of 10-14, teleports to a spot >= 140px from the player via `blinkSpot`, repeats `shots` times then leaves; `e.alpha` fades, `invuln` while faint).
- Director patterns (min level): carrier 2, shielder 4, weavers 5, blinkers 6. Elite nodes (`spec.elite`) spawn one **Hunter** at progress > 0.6 (`d.hunter`, compact HUD bar, `keep`, hp = 110 x (1 + 3% x sector level), never times out the `clearing` state, pays ~3 elites of credits + heart + magnet/cell, counts for Nanorepair).
- **ECLIPSE** (`bosses.js`, campaign system 4 only, not in the endless rotation, music index 3 = "The Final Shadow"): attacks `mirrorFan ring dashLanes overdriveWave` and phase-3 `copyUlt` which dispatches on `G.player.cls` (`COPY.striker` Dark Overdrive / `engineer` Dark Fortress: 2 `eclipsedrone` turrets + invulnerable dome, max 2 casts / `ghost` Dark Phase: blinks, slows player bullets near it). Lane beams are `G.beams` entries tagged `boss: e` (removed on phase shift / death). The autopilot (`bot.js`) steers away from enemy beam segments.

## Driving input programmatically

`input` (`src/core/input.js`, also `NEON.input`): call `input.press('dash' | 'od' | 'pause' | 'confirm' | …)` for buffered presses; set `input.mode = 'target'` with `input.tx/ty` (logical coords) to steer toward a point.

## Campaign flow

Title PLAY → `scr-campaign` (progress track of the 4 systems, LAUNCH / HANGAR + PILOT pair / BACK) → `launchRun()` → `enterSystem(0)` → `showRoute()` = the system's **overworld** (`G.screen = 'overworld'`, flying between beacons; see below) → fighting node = `startSector(nodeSpec(...))` → sector reward draft → back to the overworld. A system boss → reward draft (`afterDraft = 'next'`) → `nextSystem()` (post-boss comms, heal half the missing hull, `enterSystem(i+1)` with a fresh route). The last boss → `extract()` → `scr-extract` → campaign. Death anywhere ends the run; the next one starts at system 1. Progress: `profile.campaign.bestSys / bestRow` (furthest point reached) and `cleared` (systems ever beaten). Campaign death → `scr-over`, where UPGRADE SHIP (`upgrade` → `showCampaign('ship-btn')`, HANGAR focused) leads and RETRY is secondary.

- `src/game/campaign.js`: `SYSTEMS` (`{id, name, short, act, hue, level, step, rows, dur, bossHp, supply, pay, boss, blurb}`: `level` = row-0 difficulty, `step` per row, `dur` sector seconds (boss sector x0.7), `bossHp` boss HP multiplier, `supply` free drafts at launch, `pay` credit scale, `warm` optional per-row ease for rows 0-1, default 0.9; all systems use 0 now; levels form one continuous climb across the run), `generateRoute`, `reachableNodes`, `nodeLevel(system, row)` (rows 0-1 are eased in by `warm`), `nodeSpec`. `enterSystem` plays the intro, then `startSupply(n)` opens `n` `'supply'` drafts (`G.supplyLeft`, 0 everywhere today) before the route.
- Story (`src/game/story.js` `STORY`): system intro / `mid` (once, the first time a run reaches the middle row) / preBoss / postBoss, plus `tips`: one-time MAG lines explaining a system on first contact (overworld, route (unused since the overworld), draft, discovery, market, dock, vault, anomaly, rift, elite, hazard, ult, death, tier). `beat()` / `tip()` in `main.js` play them over the current screen (live in play), keyed in `profile.campaign.seenStory`, skipped while another line is up and when the story setting is off.
- Overworld (`src/game/overworld.js`, `overworld`; campaign only): between nodes the run flies through one zone per **leg** of the route. `showRoute()` calls `overworld.enter(run)`, which builds `run.ow` for a new leg (leg = `run.nodeId || 'start'`, seeded by `route.seed` + leg) or resumes the current one (after a level-up draft, a distress-signal event or pause; `G.enemies` keeps the leg's enemies meanwhile). Zone: `ZONE_W` 2800 x `ZONE_H` 3600 (boss approach 2200 x 2600); the ship starts at the bottom (`ow.start`); the next row's reachable nodes are `ow.exits`, left to right like the route map, in the upper half. Exits are hidden until found (within `SEE` 520 or on camera: `e.seen`, edge arrows and the map only show found ones). Flying into an exit (`DWELL` 0.85 s inside `ENGAGE_R` or confirm) → `hooks.engage` → `pickRouteNode`, so a pick closes the other exits and the next leg is a fresh zone; there is no flying past a row. **Full loadout:** `update()` runs `world.js step(dt, true)` (no director) with `field.ow` set (`state.js` `field`: camera rect `x0..y1` in world units, zone `W`/`H`, `z`), so the real `updatePlayer` / modules / dash / ult / passives / pickups / collisions run in world space. `inField(x, y, m)` replaces the screen bounds for culling (bullets, flak, floating text, enemy `entered`); `playfieldBounds()` returns the zone. Facing: `p.aim` (radians, `-PI/2` = up and always up in fights); the main gun, missiles, drones, flak, mines, saws, reflector, gravity well and the rail lance (`beam.ang` / `len`, `modules.onBeam`) fire along it, and `drawPlayer` rotates the sprite. Control (`G.scriptCtrl` = the overworld's `ctrl`): keys / pad / touch drag / mouse click-to-fly as before; **auto-aim**: `pickTarget` turns the ship to the nearest awake enemy within `AIM_R` 460 (`ow.target`, with hysteresis; asleep packs are skipped so the auto gun doesn't wake them), else the facing follows the flight; **Shift / pad shoulder locks on** (`ow.lock`, includes asleep enemies, breaks past `LOCK_R` 720 or on death, then re-locks; with no target it holds the facing); with a mouse Shift aims at the cursor, and the right stick aims (`input.aimX/aimY`). `ow.aimAt` is what the ship is aiming at; `drawTarget` draws its square (brighter, with a closing second square, when locked). Dash is the real dash (charges), not the old boost; a mouse click is not a dash. Enemies: packs (`ow.packs`, `PACKS` kinds gated by `director.foesAt(level)`, the levels' own types and sprites; `level` = `nodeLevel` of the next row - 0.3, HP x`HP` 0.6, XP x0.75 via the overworld director stand-in `setDirector`) spawn through `spawnEnemy` with `e.ow` set, so `updateEnemies` hands them to `owAI` (`enemies.setOverworldAI`) instead of the fight behaviours. A pack sleeps near home, wakes within `AGGRO` 400 or when shot, leashes past `LEASH` 1250; one pack guards each exit and an elite pack guards the `cache` site (credits + XP once its guards are down). Stragglers (`ambient`) roam in from off screen, more often the longer the leg takes. Debris (`ow.rocks`) blocks the ship, enemies, shots and pickups (`solids`). Sites (`ow.sites`, `SITES`): `wreck` credits, `data` XP, `repair` +1 hull, `cache` (guarded), `signal` (dwell) → `hooks.signal` → `openEvent(eventFor(route, site))`. The exit card (`drawCard`, fixed size above the gauges) shows the nearest found exit: type, sector, threat pips, reward, hazards, hostiles (`foesAt`) and zones, or what a stop does (`STOP_DESC`). M / Tab / pad Select / `#map-btn` toggles the map overlay (`drawMap`): the zone with fog (`ow.fog`, uncovered within `FOG_R`) above the system route strip. `overworld.leave()` (fighting nodes) and `exit()` (also called by `newWorld`) clear `field.ow`, put the ship back on the fight playfield facing up and collect leftover pickups. Level-ups open the level draft at once (`afterDraft = 'route'`); death → `gameOver()`. While `owBack` (main.js) is set, `render()` draws the overworld behind the menus an exit opens. Pause works from the overworld (`pauseFrom`, `unpause()`). `simulate` treats the overworld like the old route screen (picks a node at once). Tuning knobs are the constants at the top of overworld.js.
- `src/ui/meta.js`: render functions for campaign / route / route stop / extraction. The campaign map also carries OVERDRIVE (`tier`, cycles unlocked tiers) and FLUX CORE (`core`).
- Stops: `visitNode(node)` in `src/main.js`: market → `scr-market`, dock (shown as REST) → `scr-dock` (repair / reinforce / overclock = `'boost'` draft), vault → cache + `'vault'` draft (2 levels per pick), rift → `openEvent(RIFT)` (story.js; `run.riftLeft` hazard fights), anomaly → `scr-event` (`openEvent`). Every stop must finish via `nodeContinue()` (draft stops via `afterDraft = 'route'`).
- Map: `generateRoute` walks `PATHS` non-crossing paths up a `COLS`-wide grid (`system.rows` rows, 8 today); fixed rows: 0 combat, `floor(rows/2)` vault, `rows-1` dock; weighted types otherwise with no repeats of `LIMITED` types along a path. Combat nodes carry `reward` (campaign.js `REWARDS`), elites `'double'`; `nodeSpec` copies it to `spec.reward` and `applyFightReward` in main.js pays it at sector clear (`draftOnly` filters the sector draft by category, `extraDrafts` for elites).
- Endgame (`src/game/core.js`): heat = `run.tier` (from `profile.tier`, unlocked up to `profile.tierMax` by clearing THE VOID) + `run.deep` (Deep Grid cycle). `nodeSpec(system, node, idx, tier, deep)` tags specs; `startSector` folds `applyHeat` into the difficulty (HP ×1.4^tier ×1.8^deep, bullets / fire / spawn, credits and XP ×(1 + 0.25 heat)); boss HP via `spec.bossHp`. THE VOID's boss → reward draft (`afterDraft = 'deep'`) → `diveDeeper()` (win flag, tier unlock, ending once, `enterSystem(0)` with `deep + 1`). `leaveRun` (route ABANDON / pause QUIT) extracts a won run instead of abandoning it. Flux: `economy.gainFlux(base)` (×heat; bosses 8, Hunters 3, sector clears 1) into `run.flux`, banked in full by `settleRun` into `profile.flux`. Flux Core: `CORE` nodes (`coreCost`), `profile.core` levels copied to `player.fluxCore` and applied by `applyParts` → `applyCore`; screen `scr-core` (`src/ui/fluxcore.js`).
- Extraction rewards go in `#extract-rewards` (game over: `#over-rewards`), both filled by `meta.renderRewards(el, reward, campaignDeath)`; banking happens in `extract()` / `gameOver()` via `bankRun()` in `main.js` → `economy.settleRun(victory)`.

## Economy (`src/game/economy.js`)

- `G.run.wallet` (spendable) / `G.run.earned` (total) / `G.run.frac` (rounding carry) / `G.run.curse` (modifier id added to the next fighting node, from Contraband). `gainCredits(amount, at?)` applies `diff.credits`, `p.st.creditMul || 1` (hook for passives/parts), and ×0.5 in the debug sandbox; returns credits gained (0 in attract).
- Sources: `credit` pickups (`dropKillCredits` from `killEnemy`: 10% normal, 30% big, 2.5% swarm/mine; elites drop 3 × `diff.eliteCredits`), `sectorPayout()` (SECTOR CLEAR banner), `bossPayout()`. Value scale `unit()` = `(0.95*level - 0.1) x spec.pay`.
- Banking (`settleRun`): campaign victory 100% of wallet, campaign death 50%, sandbox death 100% of its (halved) wallet; abandoning a run banks nothing. Rank XP = `(sqrt(score)*0.08 + 20*sectorsCleared + 90*bosses + 120 (victory)) x (1 + 0.15*(act-1))` (campaign) + `run.bonusXp`.
- Pilot Rank: `rankFor(xp) → {rank, into, need}` (cap `RANK_CAP` = 15, `need` 0 at cap); `RANKS[r-1]` = cumulative XP for rank r (rank 3 = 700, rank 6 = 2500). `settleRun` returns `{earned, spent, wallet, pct, banked, total, rankXp, rankBefore, rankAfter, rankUp, victory}`.
- Black Market: `rollMarket(p, system, rng) → offers`; offer = `{id, kind: 'upgrade'|'repair'|'reroll'|'contraband', name, desc, icon, cat, tag, price, sold, blocked?, up?, amount?, hullDrawback?}`; `buyOffer(offer)` returns `''` or a reason. Prices ×(1+0.5\*(act-1)).
- Max-hull tweaks go through `p.hullMod` (dock reinforcement +, contraband −), read by `recomputeStats` (min 1).
- Upgrade helper: `rollUpgradeIds(p, kind, n, rng)` in `upgrades.js` (also behind `rollDraft`).

## Boost (`src/game/boost.js`)

- Fights only (top-down, side, chase): hold Shift / pad LB-RB-LT (the `focus` input action) / the touch `#touch-boost` hold button (`input.hold`). The overworld keeps Shift as lock-on / strafe, and the old Focus slow-down is gone for humans (the autopilot still sends `focus` to slow down).
- `updateBoost(p, dt, held)` runs in `updatePlayer`. Meter `p.boost` (0..`boostCap(p)` = `BOOST.cap` x `st.boostCap`) drains `BOOST.drain / st.boostEff` per s while `p.boosting`, refills `BOOST.regen x st.boostRegen` per s after `BOOST.delay`, needs `BOOST.min` to ignite, and burning it empty sets `p.boostLock` until the button is released. ## Gear and rarity (`src/game/rarity.js`, `src/game/parts.js`, `src/game/loot.js`)

- `rarity.js`: `RARITY` (common white, uncommon green, rare blue, epic purple, legendary orange; `weight`, `grow` per luck point), `luckFor({sys, tier, deep, find})` = sys + 0.45 x Overdrive tier + Deep Grid cycle + 3 x Rarity Find (at luck 0 a roll is Rare+ about 5% of the time, Legendary 0.1%), `rarityOdds(luck, floor)`, `rollRarity(luck, rng, floor)`.
- Items `{uid, base, slot, r, il, mods: [[affixId, v]]}`. `BASES` (7 per slot, `fx: [[stat, v]]`: positive values scale with `RARITY_GEAR[r].k` and item level, drawbacks stay fixed) and `LEGENDARIES` (4 per slot: `fx` + `unique` text + `apply` / `start`; rolling Legendary picks one). `STATS` maps a stat id to `apply(st, v)` / `text(v)`; `AFFIXES` = the random modifiers (stat, build-path tag, range, min rarity). `rollMods(..., tag)` keeps them on theme: the first modifier comes from the item's / card's own path, later ones from that path (x2 weight) or its `PATH_KIN` partner (Firepower + Crit, Modules + Overdrive, Mobility + Overdrive, Tank + Mobility, Greed + Tank), falling back to any path only when those run out. `RARITY_GEAR[r]`: base multiplier, modifier count + chance of one extra, roll-quality floor, sell value. `makeItem(slot, r, il)`, `itemLines`, `itemTags`, `itemEffect`, `sellValue`, `itemLevel({sys, tier, deep})`.
- Build paths: `TAGS` (firepower crit modules mobility overdrive tank greed). `createPlayer` sums the equipped items' tags (+ the ship's `path`) into `p.tags`; `upgrades.js UP_TAGS` maps every option to a path, `rollUpgradeIds` weights options by `1 + 0.15 x path weight` (max 4), and `cardInfo().syn` names the path once the weight is `SYNERGY_MIN` (2) or more (draft card shows `X SYNERGY`).
- Level-up cards: `rollCard(p, id, luck)` → `{r, levels, mods}` (`CARD_RARITY`: Common 1 level, Uncommon +1 modifier, Rare 2 levels + 1, Epic 2 + 2, Legendary 3 + 2; levels past the cap become extra modifiers; half-strength gear modifiers). main.js `rollRarities` rolls them for every draft but the Rest Station boost (`draftRolls`, rerolled with the cards); `applyCard` installs the levels and pushes the modifiers to `p.runMods` (applied in `recomputeStats`).
- Fabricator (`hangar.js`): `rollGear(slot, 'standard' | 'premium', find)` (`ROLL_COST` 150 / 600, premium floors at Rare), luck `fabLuck(find)` = 0.75 x `luckFor` of your best system / Overdrive tier / Deep Grid depth + the active ship's Rarity Find; `equipPart(shipId, uid)`, `unequipSlot`, `sellGear(uid)`, `sellJunk(slot)` (unequipped Common / Uncommon).
- `loot.js`: `addGear(item)` (assigns the uid, keeps `SLOT_CAP` = 8 per slot by salvaging the weakest unequipped piece for credits), `rollGearDrop(e)` from `killEnemy` / `finishBoss` (boss: always, +2 luck, Uncommon floor, 60% also a pilot find; Hunter 75%; elites 3%), `dropGear`, `dropAbility`, `runLuck()`, `runItemLevel()`. Finds land in the profile at once (kept even if the run is lost) and in `G.run.loot` / `G.run.found` for the results screen (`renderRewards` loot line). `onLoot(fn(kind, payload))` drives the toasts.
- New `p.st` fields: `find` (Rarity Find), `aegisOd` (ultimate meter per shield break), `architect`, `modRate` (module fire rate, modules.js `rateMul`), `hitIfr` (post-hit invulnerability multiplier; gear and the passive tree multiply it), `rerolls` (extra starting rerolls).
- Draft rerolls: a run starts with `START_REROLLS` (3) + `p.st.rerolls` (the Greed `rerolls` gear modifier, Rare+; the tree's Prospector notable; the Flux Core `reroll` node, +1 per level). +1 every `REROLL_EVERY` (5) levels (player.js `gainXp`) and +1 per boss. Cards can be locked (`draftLocks`, indices; the lock icon on a card, `F` / pad X on the focused card); `reroll` replaces only the unlocked cards (locked ids and their rarity rolls are kept, `rollFor(kind, avoid)`), and at least one card stays unlocked.

## Menu styling (`src/style.css`, `src/ui/screens.js`)

- Everything is sized in `em` off `#app`'s font-size (16px x playfield scale); `button { font: inherit }` keeps buttons on that scale too. Keep menu text at 0.72em or larger.

During a transit `p.auto = {x, y}` steers the jet (player.js; no dash), `cine.camera()` returns `rot/sy/skew/fx/fy/px/py` and `main.js render()` draws the world flat into an offscreen canvas and blits it rolled (`coverField` keeps the view inside the field); `cine.boost()` speeds the backdrop and the overlay adds speed streaks and the destination lower third.
- Stage views (`src/game/stageview.js`, `sv`; also `NEON.sv`): a fight zone can be flown from another camera: `side` (SIDESCROLL) or `chase` (PURSUIT); `top` is the normal view. The fight keeps running in its own top-down **virtual** frame (forward = -y, enemies enter at the top), so patterns / bosses / modules / collisions are untouched: `world.js step()` wraps the step in `sv.push()` / `sv.pop()`, which swap `view.W / H` to the virtual size (side: `screen H / 0.8` x `screen W / 0.8`; chase: 450 x 1100) and zero the safe insets. `main.js render()` calls `sv.render(ctx, k, renderWorld, getCam)`: a screen-space backdrop (bg.draw is skipped), the world rendered into an offscreen in the virtual frame (cine camera read inside it), then mapped: a quarter turn for side (virtual forward = screen right), strips warped onto a receding floor for chase (`chaseProj`: horizon at 25%, the jet's home row at 80% height at ~natural size; the far 260 virtual units fade in), then upright floating texts (`drawTexts(ctx, map)`) and the chase laser gates (drawn as standing walls). `sv.toScreen / toVirtual` map points; `sv.mapControl(c)` (player.js `control()`, human input only) turns key directions and pointer targets into the virtual frame; `input.getAnchor` and the HUD gauges use `toScreen`. `playfieldBounds()` returns `sv.bounds()` (side: left ~56% of the screen, under the HUD; chase: the near 40% of the lane). Hazards in `sv.update(dt)` (after `updatePlayer`): side terrain (`wallDepth(c, top)`: hashed low-poly ceiling / floor scrolling at 150, ramps in over 420 units, calms for fly-throughs and to 45% in boss fights; touching it pushes the jet off and calls `hurtPlayer`), chase gates (`sv.gate(gx, gw, speed)`: auto every 4.4-5.8 s during `waves` unless `director.noGates`; when one passes the jet's row it hurts outside the gap, else THREADED: +4 ult meter x grazeOd, +200 score). `sv.botHint(p)` steers the autopilot. Picking views: `generateRoute` rolls `node.views` (a view per zone; never zone 1, rows 1+, 30% combat / 45% elite, own seed so layouts don't change) and the boss node's `arenaView` (`BOSS_VIEWS`: hydra side, omega chase, 50%); `nodeSpec` copies them to `spec.views / arenaView`; `spec.view` forces a whole sector (debug: `NEON.startSpec({view: 'side'})`, or `NEON.stage('chase')` mid-fight). The director's `break` (and the boss `clearing` arena flight) passes `swap` to `cine.transit(kicker, name, boss, swap)` (no roll, a straight push) and sets `d.swapTo`; at 42% of the fly-through `changeView` runs `sv.enter(mode)` (jet to `sv.home()`, in-flight shots / particles / texts cleared, pickups moved onto the jet), `cine.retarget`, a white flash, and `d.onView` (main: one-time MAG tips `view_side` / `view_chase`). `startSector` and `showRoute` reset to top. Boss variants (`bosses.js VARIANTS`, `bossVariant(id, view)`): `e.view` picks `ATTACKS[kind].views[view]` cycles and a closer `homeY`; HYDRA side = Abyssal Leviathan (`tide`, `geyser` beams across the lateral axis), OMEGA chase = Event Horizon (`gates`, `lanes` floor beams). The exit card names the zone and view (`ZONE 3 PURSUIT`, `BOSS ARENA · SIDESCROLL`).
- Map transitions: `showRoute` opens `scr-route` with `guard: true` (held keys and a resting cursor can't move the map cursor until released) and `routeZoom('in', node)`: the map pulls back out of the node just left. Picking a node in the UI runs `routeZoom('out', btn)` (the map dives into it, 0.38 s) before `pickRouteNode`; the fight then opens with the `cine.nodeStart` push (1.16x). CSS-only (`#scr-route.zoom-in/.zoom-out`, transform-origin `--zx/--zy`). `NEON.pickNode` and `simulate` skip the animation.
- Beats: `banner(title, sub, color, dur, kind, kicker)`: `kind` `'start'` (node opening: `NODE n / rows`, type, modifiers; rules grow from the centre), `'clear'` (`NODE CLEAR`; rules close in from the edges), `'secured'` (system boss down: `SECTOR SECURED`, full-width band with a sweep). Plain banners (`kind` null) are the endless sandbox, HUNTER and WARNING. Drawn by `drawBeat` in `hud.js`.
- Sector intro (`src/render/sectorIntro.js`): `playSectorIntro(sys, idx, done)` in `main.js` sets `G.screen = 'sector-intro'` (world frozen), runs ~3.7 s of warp streaks → drop flash (grid blast) → per-system motif (GENESIS square lattice, CRIMSON tide bands, CYCLONE vortex, VOID collapsing rings) behind a `SECTOR 0n · ACT n` card with the scrambled-in name and blurb, then calls `done` (dialogue, supply, route). Confirm / back / dash / tap skips to the fade. `NEON.launch` skips it unless `opts.intro`; `simulate` skips it.
- Debug: `NEON.launch(sys, {story})` skips dialogue by default; `NEON.event(id, {rng})`, `NEON.pickEvent(i)`, `NEON.eventState()`, `NEON.comms`, `NEON.extract()`. `simulate` auto-skips blocking comms and picks the first available event choice (`opts.eventPick(event, session) → index`).

## Boot intro (`src/game/intro.js`)

- `boot()` plays it while `profile.seenIntro` is false (first boot, or after a progress reset), else goes straight to the title; Settings has REPLAY INTRO (hidden in the pause menu's settings). It ends in `toTitle(true)`, which plays the `.logo.slam` entrance.
- ~19 s of live engine on a fresh attract world (`G.screen = 'intro'`, simulated, sfx unmuted): ECHO's six-ship squadron (one per hull, drawn by `intro.draw` after `renderWorld`) holds the Genesis gate until the Signal deletes them, black, MAG wakes ECHO, the hero reveal (aura, name card), then director waves and a scripted Striker Overdrive with a chained clear. The timeline is the `CUES` table plus `at(t)` beats in `update`; text lives in `#intro` (absolutely placed, typed with reserved heights).
- Skip: Esc / Back / pad B skips; any other key, click or tap arms PRESS AGAIN TO SKIP (and unlocks audio, so the rest plays with music), a second press skips.

## Relics and achievements

- `src/game/collectables.js`: `THEMES` (one per campaign system via `system`, plus `junk`, 20% of finds in any system), `RELICS` (`{id, theme, rarity: common|rare|legendary, name, text, icon}`), `RARITY` (price, drop weight), `buyRelic(id)` / `openCapsule()` (return `''` / `{err}`), `rollRelicDrop(e)` (called from `killEnemy` and boss `finishBoss`; spawns a `'relic'` pickup tagged with the field theme), `collectRelic(pk)` (from `collectPickup`). Listeners: `onRelic(fn(relic, source))`, `onSetComplete(fn(theme))`.
- `src/game/achievements.js`: `ACHIEVEMENTS` (`{id, group, tier: b|s|g, name, desc, hidden?}`), `achTick(dt)` runs every frame from `main.js` and polls `G` / `profile` (screen edges, hp/dash/ult edges, director state, counters), so most achievements need no gameplay hook. Explicit hooks: `achEvent('kill', e)` (onEnemyKilled) and `achEvent('heartFull')`. `achInit()` grants what an older save already earned, silently. `unlock(id)` pays `TIERS[tier].reward` to `profile.credits`. Simulate does not run `achTick`.
- UI: `scr-gallery` / `scr-achievements` (`src/ui/gallery.js`, title menu), toasts in `#notes` (`src/ui/toasts.js`, `notify({kicker, title, icon, color, shine})`).
