# Neon Glitch Hell: Overdrive (LÖVE build)

Rebuilt from the browser prototype into a desktop-focused LÖVE 11.x game while keeping the neon bullet-hell feel.

## Running
- Install [LÖVE 11.x](https://love2d.org/).
- From the repo root: `love .`
- Default window: 1280x720, resizable, high-DPI enabled.

## Controls
- `Enter`/`Space`: start or restart.
- `WASD`/Arrow keys or mouse: move the ship (mouse steers toward cursor).
- `P`/`Esc`: pause/resume.
- `R`: restart mid-run.

## Notes
- Game launches in demo/attract mode; press start to play.
- Bombs, shields, and power/life pickups behave like the original web version.
