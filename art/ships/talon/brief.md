# TALON generated ship views

TALON is a marksman ship with a single central long barrel, swept hooked claw wings, and twin close aft engines. Its overhead image keeps the long narrow spine and hooked tips, while its side view foreshortens the claws and exposes the single muzzle. The pursuit view puts two empty engine faces in the foreground and foreshortens the nose. Source top had a few isolated alpha=1 edge pixels, so the selected source received one pixel of transparent padding; the generated original is retained as top-generated-v1.png. Anchors below include that one-pixel offset.

Runtime exports are 256×256 RGBA PNGs generated with `tools/ship_assets.py`; the manifest records source and runtime hashes, prompt paths and measured original-source anchor pixels.
