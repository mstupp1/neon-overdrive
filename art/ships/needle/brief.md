# NEEDLE generated ship views

NEEDLE is a long, slender interceptor with one centered lance barrel and one centered aft engine. The selected v2 top edit widens its compact swept aft fins and slightly shortens the nose lance while preserving the slender silhouette. The v2 top and side edits brighten pale-metal bevels and stock lime accents for small-sprite readability. The pursuit source remains the accepted v1 rear view, with its single engine face and foreshortened body.

The original v1 top and side sources and prompts remain preserved beside the v2 revisions. Each selected source, exact prompt, input references, source/runtime hashes, source dimensions, and measured muzzle/engine anchors are recorded in `manifest.json`.

All runtime views are 256×256 RGBA PNGs exported with `tools/ship_assets.py` and an 8-pixel transparent margin. Specs map original-source anchor coordinates through the recorded runtime `contentBox`.
